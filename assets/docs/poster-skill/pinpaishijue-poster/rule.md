# Skill: 活动管理生成一张宣传海报并配套 AI 推文功能

## 1. 能力定义

**能力名称：** 活动海报 + 活动推文一体化生成  
**能力目标：** 根据活动主题、场景、产品与传播目标，自动生成一张符合品牌视觉规范的活动宣传海报，并配套生成可直接发布的活动推文文案。

**核心价值：**

- 把单次活动执行沉淀为可复用的内容生产资产
- 海报负责视觉传播，推文负责信息转化
- 形成“活动主题 → 海报视觉 → 传播文案 → 复盘沉淀”的完整闭环
- 可纳入个人 AIPM作品集、Git 技能库或内容生成 SOP

---

## 2. 海报生成规范

### 2.1 视觉风格

**风格定位：** 全幅社论动作海报  
**关键词：** 明亮户外、开阔天空、低角度广角、强动作感、高对比光影、粗体排版、商业真实感、轻微印刷颗粒

### 2.2 必见视觉特征

| 模块 | 规范 |
|---|---|
| 画面主色 | 天空蓝、青蓝、奶油白、深阴影 |
| 主标题 | 暖奶油色超紧缩无衬线块状大写字母 |
| 标题处理 | 巨大文字位于主体后方，被画布裁剪，形成层次感 |
| 主体表现 | 超大动作人物或产品斜切突破文字层 |
| 镜头语言 | 低角度、近距离广角、冻结运动、强对角线 |
| 辅助文字 | 白色微型社论文字，紧凑网格排列 |
| 底部信息 | 奶油色信息簇，包含活动提示信息 |
| 强调色 | 集中在英雄产品、活动道具或主体焦点上 |
| 光影 | 正午阳光、清晰阴影、高对比 |
| 装饰原则 | 最小装饰，密集动能布局 |

### 2.3 海报固定文案

| 位置 | 文案 |
|---|---|
| 主标题 | `{MAIN_TEXT}` |
| 副标题 | `{SECONDARY_TEXT}` |
| 底部提示 | 扫码了解活动详情 |
| 右下角标识 | 小起 |

> 注意：只出现“扫码了解活动详情”文字提示，不实际绘制二维码图形。

### 2.4 生成约束

**必须避免：**

- 真实品牌标志
- 水印
- QR 码
- 漫画半色调
- 3D 渲染感
- 暗室场景
- 柔调光影
- 主体过小
- 画面过杂
