# SKILL：社区研学统一风格科普海报生成规范
（可复制交付任意 AI，固定版式 + 视觉 IP + 文案结构）

> 
> 用途：输入科普文字，AI 严格遵循本规范产出和参考图完全一致画风、布局、组件的 A4 竖版科普海报，用于 PDF 研学手册 / 社群日发单页，沉淀为可复用 AIGC 资产，适配 AIPM 作品集流水线。

## 一、基础画布参数

1. 尺寸：A4 竖版，960×1351 像素
2. 背景：浅米黄做旧纸张肌理，淡淡的宣纸质感，纯白色禁止使用
3. 整体画风：扁平治愈手绘插画，柔和粗轮廓线条，低饱和马卡龙暖色调，童趣但不低幼，面向青少年与社区家长；无写实光影、无 3D 渲染。

## 二、页面自上而下固定布局（顺序不可调换）

### 区域 1｜顶部板块标签（页面最上端）

格式：`◎自然科学板块` / `◎青少年身心科普板块`
字体：细棕色手写字体，居中放置

### 区域 2｜大标题区（视觉核心）

1. 内容模板：`TipXX + 一句话科普主标题`
2. 字体：粗拙圆润棕色卡通手写大字，换行排布，居中，字号最大，醒目厚重

### 区域 3｜小提问行（标题下方）

固定前缀`◎小提问：xxxx？`，细棕色字体，居中

### 区域 4｜中间插画区（固定 IP 组件，强制全部保留）

画板主体：木质立式画架，画板内部绘制贴合本期科普主题的简约插画元素
**固定常驻 IP 元素（每张海报必须携带，不可删减）**
- 画架左下角：黄色趴卧小猫
- 画架左右两侧：绿色盆栽绿植
- 画架底部地面：堆叠书本、白色咖啡杯、红色笔筒、红色小收纳盒、散落画纸
- 画面点缀装饰：四角黄色星星、小云朵、箭头曲线、放大镜、小落叶，零散柔和分布，不要拥挤

> 
> 规则：仅画板内部更换和文案匹配的主题图案，周围全套 IP 布景永久不变，形成系列视觉资产。

### 区域 5｜底部圆角文本框（承载全部科普文字，页面最下方）

1. 外框：浅橙棕色圆角粗边框，内部底色与整张背景一致（浅米黄）
2. 文本排版规则，严格使用图标前缀，每条单独一行：
⭐科普普小 tip：开篇一句话结论
✅正文解释段落 1
✅正文解释段落 2（可选）
⚠️风险 / 提醒段落（按需保留）
◎来源：XXX 权威科普平台

> 
> 标点、符号样式和样图保持统一，文字左对齐，行距宽松，避免密密麻麻堆砌文字。

## 三、色彩系统（锁定色卡，保持系列统一）

禁止高饱和刺眼荧光色；整体通透柔和，治愈安静。
