# PPT碎片组件库
> 全部为结构模板，颜色、图标、纹样由theme主题包进行替换。

## 1.小标题前缀组件
结构：`【装饰符号】｜模块标题`
> 示例：🔹｜社区多元价值
> theme可替换符号为：葫芦图标、圆点、小方块、线条标记。

## 2.重点提示卡片组件
- 容器：圆角卡片，内边距20px。
- 结构：卡片标题 + 正文说明；适合放核心结论、重点提醒、核心数据。
> theme可以修改卡片底色、边框、角落装饰IP元素。

## 3.横向分割线组件
- 基础：一条水平分割线；
- 扩展：分割线一端附带小装饰（图标/纹样）。

## 4.引用块组件
> 用于放理念、slogan、金句。
- 左侧竖装饰条 + 引用文本；文字适度放大，行高宽松。

## 5.指标小卡片（数据碎片）
- 单卡片：大数字高亮 + 简短标签说明。
> 适合多指标并排展示；数字高亮颜色由theme主题包控制。

## 6.列表项碎片
- 符号前缀 + 标题 + 简短解释。
> theme主题包可以替换前缀符号（葫芦、圆点、方块）。

## 使用约束
1. 碎片组件不要叠加过多，一页内同类碎片不要超过4个。
2. 碎片仅做局部增强，不能替代完整页面骨架。
