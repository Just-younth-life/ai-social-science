# PPT封底规范
## 三种封底骨架模板
### 模板A｜致谢收尾页（汇报PPT最常用）
- 主文本居中：感谢观看 / 谢谢聆听
- 可选：底部放置单位、联系方式、项目slogan愿景。
- 大量留白，不堆砌多余正文。

### 模板B｜愿景结语页（方案、项目策划）
- 居中放置一句项目愿景slogan；下方简短补充一句话说明。
- 不放置大段文字，适合路演、项目成果汇报。

### 模板C｜Q&A问答页
- 页面大标题：Q&A｜交流答疑
- 页面干净，留白充足，可放简单logo，不要塞入业务正文。

## 布局约束
1. 内容放在页面安全边距以内；不要贴边。
2. 建议视觉元素、装饰纹样呼应封面，实现首尾闭环。
3. 禁止把业务大段正文、数据表格放在封底。

## 文字层级
- 主文字：36‑48px
- 补充小字：14‑18px

## 与主题包联动
- 通用骨架只定义排版；色彩、IP装饰、特殊字体由theme主题包注入。
- 例如葫芦主题封底会加入淡水墨葫芦藤蔓；社区科普主题会加入简约红色元素。
