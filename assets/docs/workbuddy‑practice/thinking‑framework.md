# 顶层思维范式 & 自适应难度调度规则
## 全套思维范式集合
### 核心三范式
1. **本体论**：认知建模，厘清实体、概念、职责边界，消除歧义，先定义本质再谈执行。
2. **U型思考（U‑Theory，奥托·夏莫）**：共同启动 → 共同感知 → 深度洞察 → 共同创造原型 → 迭代进化；适合多方团队共创。
3. **乾坤架构**：乾=顶层纲领总目标；坤=子业务模块；一主多从，顶层统摄，子模块解耦协同。

### 扩展增效范式
4. **第一性原理**：锁定底层不可动摇约束公理；区分客观事实与主观假设，拒绝无脑套用案例模板。
5. **系统思维‑冰山模型**：事件→行为模式→系统结构→底层心智假设；识别利益相关方、反馈回路、延迟副作用。
6. **二阶思维**：评估直接收益、二阶连锁副作用、长期风险，输出风险清单。
7. **斯坦福设计思维**：共情→定义问题→发散构思→原型→测试，面向终端用户设计。
8. **MECE + 苏格拉底诘问**：模块相互独立完全穷尽；追问依据、反例，消除逻辑漏洞。
9. **假设‑验证框架**：强制区分【已验证事实】/【待验证假设】，假设必须显式标记，禁止猜想当结论。

## 三级自适应调度规则（控制API消耗）
### L1｜轻量简易任务
适用：start工作日志、简短片段、推文、物资清单、简单待办整理
✅启用：本体论 + MECE
❌禁用：U型思考、乾坤架构完整流程、冰山根因、二阶推演、假设验证完整流程
输出：精简直奔结果，极速交付。

### L2｜中等常规任务
适用：完整单场会议纪要、单场活动拆解、单渠道分发方案、单次SOP
✅启用：本体论 + MECE + 简易乾坤架构 + 基础假设‑验证
❌禁用：完整U型全链路、冰山深层根因挖掘、多阶连锁推演
输出：结构完整，仅标记关键待确认点，不展开长篇风险。

### L3｜重度复杂共创任务
适用：整套体系0‑1初稿、多板块联动项目、年度顶层规划
✅启用：**全部9套范式完整链路**
输出：完整分层方案、风险清单、待调研事项、落地路径。
