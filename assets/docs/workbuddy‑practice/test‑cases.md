# WorkBuddy专家回归测试用例
> 修改专家prompt之后，执行下面用例做回归验证，确认难度分级逻辑正常。

## L1 轻量任务测试
指令：
写一条上午参与三地科普推进会议记录的 start 格式工作日志
预期输出：仅单条start日志条目，无架构、无风险推演、无深度分析。

## L2 中等任务测试
指令：
基于童心绘成长线下活动录音转写文本，整理完整可粘贴 Word 的会议纪要，整合我手写的现场待办计划
预期输出：结构化完整纪要，待办清单；仅少量关键待确认标记，无长篇风险推演。

## L3 重度全范式测试
指令：
用全套顶层思维范式，输出社区科普・童心绘成长线下心理活动完整 0‑1 共创初稿方案
预期输出：本体建模、U型共创流程、乾坤架构、二阶风险清单、事实/假设区分完整内容。
